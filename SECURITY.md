# Security

This is an unsupported community repository, but packages can run on firewall
systems. Do not publish an exploit, credentials, private addresses, or detailed
exposure steps in a public issue.

If GitHub private vulnerability reporting is available for this repository,
use the repository's **Security > Report a vulnerability** flow. Otherwise,
contact the repository owner `@mimugmail` through GitHub and request a private
channel without including exploit details.

Provide:

- affected package, package version, OPNsense version, and FreeBSD package ABI;
- impact and required configuration;
- minimal reproduction in a disposable environment;
- relevant redacted logs and package/source references; and
- any known workaround, rollback, or mitigation.

There is no guaranteed response-time or support commitment. Public reports may
be opened only after secrets and actionable exploit details are removed or the
maintainer agrees that disclosure is safe.
